# OsmAnd resources

LumaScope does not bundle, stage, redistribute, or package the OsmAnd resources tree.

To use the OsmAnd renderers, download the resources separately from the upstream project:

- https://github.com/osmandapp/OsmAnd-resources

After extracting the repository, select its resources root folder in the LumaScope Download tab. The selected root must contain:

- `rendering_styles/default.render.xml`

LumaScope stores only the selected local folder path in its application settings. The resources remain external to the application installation and are not copied into the LumaScope package.

The OsmAnd resources are maintained by the OsmAnd project and remain subject to the terms and notices provided by that project. Consult the upstream repository for current licensing information.
